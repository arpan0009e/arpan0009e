## 🚀 Featured Projects

### 🩺 [MedExplain](https://github.com/arpan0009e/MedExplain): Medical Report Explanation Platform

> **The problem:** medical reports are full of jargon patients can't parse.
> **The approach:** an LLM + RAG pipeline that explains the report in plain language, grounded in authoritative medical sources instead of the model's guesswork.

- **FastAPI + Pydantic** backend with typed request/response models
- PDF/document processing, embeddings and **vector-database retrieval** so answers cite real sources
- **MongoDB** persistence keeps context, so patients can ask follow-up questions
- `Python` `FastAPI` `Pydantic` `RAG` `Vector DB` `MongoDB` `LLM`

```mermaid
flowchart LR
    A[📄 Medical Report PDF] --> B[Parse & Chunk]
    B --> C[Embeddings]
    C --> D[(Vector DB)]
    E[❓ User Question] --> F[Retriever]
    D --> F
    F --> G[LLM]
    G --> H[✅ Patient-friendly Answer]
    G --> I[(MongoDB)]
```

### ✈️ AI Travel Planner

> **The problem:** LLM travel plans often include places that don't exist or routes that make no sense.
> **The approach:** let Gemini draft the itinerary, then ground every stop with the Google Maps Places API.

- Personalized, **budget-aware, day-by-day** itineraries from destination, days and budget
- Powered by the **Google Gemini API**, grounded with the **Google Maps Places API**
- Deployed on **Streamlit Community Cloud**
- `Python` `Gemini API` `Streamlit` `Google Maps API`

```mermaid
flowchart LR
    A[🧳 User Input<br/>Destination, Days, Budget] --> B[Streamlit UI]
    B --> C[Prompt Builder]
    C --> D[Google Gemini API]
    D --> E[Draft Itinerary]
    E --> F[Google Maps<br/>Places API]
    F --> G[Ground Places &<br/>Optimize Routes]
    G --> H[✅ Day-by-Day Itinerary]
    H --> B
```
